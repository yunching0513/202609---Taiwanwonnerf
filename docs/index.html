全台生活街道
指認地圖

以OpenStreetMap路網為底，估算每一路段之路寬，指認15公尺以下、可能成為生活街道（living street／しなやかな道）的道路；另可切換為荷蘭Sustainable Safety的三層道路功能分級（Through／Distributor／Access）。放大到街廓層級可點選任一路段查看依據。

依荷蘭 Sustainable Safety（Duurzaam Veilig）三層功能分級
國道、快速公路（Stroomwegen）
省道、縣道、鄉道、市區幹道（Gebiedsontsluitingswegen）
市區道路、巷弄（Erftoegangswegen；即左側路寬分級之全部路段）
各縣市 ≤12公尺道路比例
